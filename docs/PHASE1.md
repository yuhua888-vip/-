# PHASE 1 实现与验收记录

状态：**代码实现完成，自动测试通过；实机视觉及触摸验收待完成。**

## 已实现

1. 完整原仓库审查与原版归档；严格 TypeScript 模块、锁文件和可重复构建。
2. 独立 8 副牌引擎；自然牌、完整第三张规则、对子、和退本、经典佣金与庄六赔半两种明确规则。
3. 整数最小单位账本、原子投注、撤销/清空/加倍/续押、结算 ID 去重。
4. 完整本地快照、刷新中断恢复、存储失败回滚、修订号校验、同浏览器单桌独占。
5. 午夜蓝绿牌桌、象牙色文字、银色装饰、独立牌靴、五投注区与六档筹码。
6. 筹码飞行、堆叠、反向撤回、赢家区域反馈、输方收取、赢家追加与返还筹码。
7. 从牌靴起点依次发 P1/B1/P2/B2，抽取、滑行、落桌、翻牌及补牌的统一时间线。
8. 程序绘制的高清牌面、点数排列和 Q 原创牌背；正常牌面按需缓存。
9. 四角咪牌：局部裁剪、卷折阴影、鼠标/触摸 Pointer Events、阈值回弹、20 秒自动开牌、键盘逐步揭牌或直接开牌。
10. 四姿态皇后：等待、停止下注、发牌、赔付；姿态淡入过渡、轻微呼吸、事件驱动；DealerBrain 可替换但不接 AI API。
11. AudioManager：选择/落筹/堆叠/滑牌/翻牌/咪牌摩擦/倒计时提示/结果音，独立总音量、音乐、环境、音效通道，咪牌时压低背景声音。
12. 珠盘、大路、大眼仔、小路、曱甴路切换；展开/折叠、统计和最近 100 局记录。
13. 自动开牌、节奏、减少动态效果、音量、静音、规则设置；响应式断点、安全区域、键盘焦点、语义按钮。

## 修复

- 消除同一桌面同时出现“庄六赔半”和“庄 0.95”的规则矛盾。
- 50 筹码下注庄、经典佣金获胜时准确返还 97.5，修复原 `Math.round` 变成 98 的错误。
- 续押将当前投注可退回金额纳入可用资金，替换投注一并提交。
- 拒绝负数、非有限值、错误位置、非整筹码与超额投注。
- 阻止重复开局、连续或跨其他记录的重复结算。
- 生产启动不再执行会改写全局结算状态的 100 局模拟。
- 中断、刷新或动画失败后使用保存的原牌局结果恢复，不重新随机发牌。
- 取消动画能结束等待，失败路径恢复 controls 或保留待结算状态供重试。
- 修正大路长连后错误向最远列换色以及开局和丢失。
- 移除 CDN 样式/图标/字体运行时依赖、禁止缩放和全局固定高度裁切。
- 修正快速重新拖动时旧回弹动画可能覆盖新手势的竞态。
