## 启动

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm test
npm run dev
```

开发服务器会在终端输出本机访问地址。游戏使用 Web Locks 和 Web Crypto，需要 **HTTPS 或 localhost 安全上下文**；不要通过双击 HTML 的 `file://` 地址运行。

## 构建与静态部署

```sh
npm run build
```

完整可部署产物在 `dist/`。也将编译后的 `assets/app/` 和 `assets/queen.css` 提交进仓库，保持原项目直接由 GitHub Pages 从仓库根目录提供静态内容的方式可用。修改 TypeScript/CSS 后必须重新构建再提交，不能手改编译后的 JS。

本次只准备独立改动供审查；没有更改现有站点的托管设置，也没有合并主分支。

## 规则与存档

默认保留原程序实际使用的经典佣金规则：庄净赔 0.95，闲净赔 1，和净赔 8，对子净赔 11。可在清空投注后切换为“庄六赔半”；赔率和帮助文案从同一规则配置派生。

一个虚拟筹码等于内部 100 个最小单位。下注以整筹码为单位；赔付保留到 0.01 筹码，不舍去 50 筹码庄赢退回 97.5 等合法小数。

牌靴包含 416 张，不烧牌；剩余 60–75 张为切牌区间，仅在下一局发牌前洗牌，绝不在当前局续接新牌靴。

投注、发牌计划和结算以完整快照保存；重新打开时，已经确认发牌的牌局按已保存的同一组牌完成结算。未确认发牌的投注原样保留。存档异常不会静默重置余额。一个浏览器同一时间只有一个标签页可以操作牌桌。

存档是本地试玩记录，用户能通过开发者工具修改本地数据；它不是安全的服务器账户，不可用于多人或任何真实价值系统。清理浏览器数据、更换浏览器、无痕会话结束都会失去本机进度。牌路与详细历史保留最近 1,200 局，界面历史表展示最近 100 局；账本保留最近 2,000 笔详细记录、校验起点和操作去重 ID。
